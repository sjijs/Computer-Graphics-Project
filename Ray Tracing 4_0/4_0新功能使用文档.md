# Ray Tracing 4.0 新功能使用文档

本文档说明 4.0 版本中新增的核心能力，以及如何在工程中使用它们。

## 1. 本版本新增能力

1. Disney 基础材质模型
- 支持 `baseColor`、`metallic`、`roughness`、`specular`、`clearcoat`、`sheen`。
- 支持 `baseColor/metallic-roughness/normal/emissive` 纹理输入。

2. 新积分器路径
- 材质接口升级为 `sample_bsdf / eval_bsdf / pdf_bsdf`。
- 路径积分升级为 `throughput` 迭代写法。
- 支持 NEE（下一事件估计）+ MIS（多重重要性采样）+ 俄罗斯轮盘终止。

3. 外部模型导入升级
- 支持读取模型顶点 UV 与法线，并进行三角形插值。
- 支持按子网格材质槽加载 Assimp 材质与贴图。
- 支持关闭 embedded materials，使用你自定义的 Disney 材质覆盖模型。

## 4. 如何使用 Disney 材质

## 4.1 纯参数材质

```cpp
auto disney_plastic = make_shared<disney_material>(
    color(0.86, 0.22, 0.20), // baseColor
    0.0,                     // metallic
    0.35,                    // roughness
    0.55,                    // specular
    0.0,                     // clearcoat
    0.10                     // sheen
);
```

## 4.2 纹理驱动材质

```cpp
auto tex_disney = make_shared<disney_material>(
    make_shared<image_texture>("solar system/earth_day_8k.jpg"),
    0.2,
    0.65,
    0.5,
    0.25,
    0.0
);
tex_disney->set_metallic_roughness_texture(make_shared<image_texture>("solar system/moon_8k.jpg"));
tex_disney->set_normal_texture(make_shared<image_texture>("solar system/saturn_ring_8k.png"));
```

## 5. 如何使用 NEE + MIS

在相机中开启：

```cpp
cam.enable_nee = true;
cam.enable_mis = true;
```

建议显式指定灯光采样几何，减少噪声：

```cpp
auto lights = make_shared<hittable_list>();
lights->add(area_light);
lights->add(fill_light);

cam.light_sampler = lights;
cam.sample_world_for_direct_light = false;
```

说明：
- `light_sampler` 只放发光几何体时，直接光采样更稳定。
- 若不设置 `light_sampler`，可以退化为对整个世界采样，但效率和方差通常更差。

## 6. 如何导入外部模型并贴图渲染

## 6.1 使用模型自带材质与贴图（推荐优先）

```cpp
ModelLoadOptions opt;
opt.scale = vec3(1.0, 1.0, 1.0);
opt.translate = vec3(0, 0, 0);
opt.center_model = true;
opt.flip_winding = false;
opt.import_embedded_materials = true; // 默认 true

auto fallback = make_shared<lambertian>(color(0.7, 0.7, 0.7));
auto model = load_model_as_hittable("models/your_model.obj", fallback, opt);
world.add(model);
```

当模型文件包含材质引用时，导入器会尝试读取：
- baseColor
- normal
- metallic
- roughness
- emissive

## 6.2 强制覆盖模型材质（你指定 Disney + 贴图）

```cpp
ModelLoadOptions opt;
opt.scale = vec3(2.0, 2.0, 2.0);
opt.translate = vec3(0, 0, 0);
opt.center_model = true;
opt.import_embedded_materials = false; // 关闭内置材质

auto override_disney = make_shared<disney_material>(
    make_shared<image_texture>("solar system/jupiter_8k.jpg"),
    0.08,
    0.42,
    0.55,
    0.20,
    0.05
);
override_disney->set_metallic_roughness_texture(make_shared<image_texture>("solar system/mars_8k.jpg"));

auto model = load_model_as_hittable("models/bunny.obj", override_disney, opt);
world.add(model);
```

## 7. 常见问题

1. 模型导入后全黑或很暗
- 检查是否存在有效光源。
- 检查是否开启 `enable_skybox` 或添加发光体。

2. 噪点过多
- 提高 `samples_per_pixel`。
- 使用 `light_sampler` 指向灯光集合。
- 保持 `enable_nee = true` 与 `enable_mis = true`。

3. 模型大小或位置不对
- 调整 `ModelLoadOptions.scale` 与 `translate`。
- 通常开启 `center_model = true` 更容易摆放。

4. 贴图看起来错位
- 确认模型本身带有 UV。
- 确认贴图路径正确、文件可访问。

## 8. 推荐调参起点

静帧高质量渲染建议：
- `samples_per_pixel = 400 ~ 1000`
- `max_depth = 80 ~ 120`
- `enable_nee = true`
- `enable_mis = true`
- `sample_world_for_direct_light = false`（配合 `light_sampler`）

以上设置可作为 4.0 阶段高拟真 CPU 渲染的基础配置。
